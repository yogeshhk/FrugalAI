## Rules the drafts follow
- Plain, human register: short paragraphs, first person, contractions, no em dashes, no hype words.
- Story first; the posts keep numbers out, the stories carry a few with the device named, the full tables stay in
  the project READMEs. A claim must be backed by the project README; a mixed result is reported as mixed.
- Code snippets are real excerpts; a shortened or simplified one says so.
- Never name a person other than the author, and never include personal contact details.

## Banner style (same for all)
Paste this block first, then the topic's scene line from its `_linkedin.md`, into ChatGPT or Gemini image generation.

> Warm hand-drawn illustration, soft watercolour and ink, in an Indian setting. Muted earthy palette (terracotta,
> indigo, ochre, leaf green) on an off-white paper background. Simple, friendly, uncluttered, plenty of empty space
> on the left third for text. Landscape, 1200 x 627 pixels. In the top-left corner, small clean sans-serif text
> "Frugal AI". One short title in large clean sans-serif lettering on the left: "<TITLE>". No other text, no logos,
> no brand names, no photorealism, no screens showing readable code.

Check every generated image before use: image models misspell text, so regenerate or add the title yourself in an
editor if the lettering is wrong. Keep the alt text from each file.

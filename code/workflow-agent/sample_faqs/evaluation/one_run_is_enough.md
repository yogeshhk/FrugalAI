# FAQ: Is a single timing run enough to quote a model's speed?

**Question.** I ran my model once and it produced 20 words a second. Can I put that number in my report as its
speed on this machine?

**Answer.** One run is a single sample, and speed varies from run to run because of other programs, heat and the
length of the answer. A fairer report repeats the run several times, throws away a warm-up run, and gives the median
together with the lowest and highest values, plus the device, the model file and the date. A number without those
details cannot be compared with anyone else's, and may not repeat on the next day.

**The fallacy, named directly.** "My one measurement is the speed" takes a single noisy observation for a property
of the machine, and hides how much the result moves between runs.
